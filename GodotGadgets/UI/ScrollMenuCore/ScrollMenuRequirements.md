# 滚动选择菜单（Scroll Select Menu）需求文档

## 核心需求

- [ ] **数据驱动**：菜单项来源于可排序的数据集合，支持文本、图标、目标场景等属性。
- [ ] **固定可见项数量**：同时显示 N 个菜单项（例如 3 或 5），其余项通过滚动显示。
- [ ] **焦点项高亮**：始终有一个当前选中项，视觉上与其他项有明显区分（如放大、变色、边框加粗等）。
- [ ] **方向输入导航**
    - [ ] 支持键盘（上/下箭头键）
    - [ ] 支持鼠标滚轮
    - [ ] 支持手柄（左摇杆 / 十字键）
- [ ] **滚动跟随焦点**：焦点移动时可见区域自动滚动，保持焦点项在可见区域内（始终居中或边界对齐）。
- [ ] **边界处理**：到达列表头部/尾部时停止移动，或根据设置支持循环（见扩展）。
- [ ] **平滑过渡动画**：滚动时菜单项之间使用平滑的位置过渡或淡入淡出效果，避免生硬跳跃。
- [ ] **确认操作**：玩家按下“确认键”（回车、手柄 A、鼠标左键点击）触发当前焦点项对应动作（如切换场景、打开设置等）。
- [ ] **输入抽象**：不直接依赖具体物理按键，使用 InputAction 或事件订阅（如 OnNavigateUp、OnNavigateDown、OnConfirm），便于多平台适配及键位自定义。

## 扩展需求

- [ ] **循环滚动**：到达顶部再向上滚动时焦点跳回底部，反之亦然。可搭配无限滚动视觉效果。
- [ ] **非均匀尺寸或动态间距**：焦点项与普通项宽度/高度不同（如中间项放大），或项间距随焦点位置动态变化。
- [ ] **嵌套子菜单**：选中某项可展开下一级菜单，返回时恢复父级焦点。
- [ ] **实时数据更新**：列表项运行时动态增减（如解锁新功能后出现新菜单项），焦点和可见范围自动调整。
- [ ] **可定制化样式模板**：焦点项、普通项、禁用项可分别配置独立视觉模板。
- [ ] **快捷跳转**：支持按字母键快速定位到对应首字母的菜单项；长按方向键可连续滚动并逐渐加速。
- [ ] **触屏滑动手势**：支持手指滑动列表，抬起时自动贴合到最近的菜单项。
- [ ] **惯性滚动**：鼠标滚轮或触屏快速滑动后带有惯性效果，并最终吸附到邻近项。
- [ ] **辅助功能（Accessibility）**：支持屏幕阅读器，焦点变化时播报当前项名称。
